Firebase Setup

Connected to Firebase

Your data automatically syncs across all devices using this Firebase project.

Connect to Firebase to sync your data across multiple PCs. Quick one-time setup:

Setup Instructions (2 minutes)

  1. Go to console.firebase.google.com and sign in with Google
  2. Click "Create a project" (or "Add project"), name it anything (e.g. "peptide-store"), click through defaults
  3. In your project, click the gear icon → Project settings
  4. Scroll down to "Your apps" and click the Web icon (</>) to add a web app
  5. Give it a nickname (anything), don't check Firebase Hosting, click Register
  6. You'll see a firebaseConfig code block — copy the entire config object
  7. In the left sidebar, click "Build" → "Realtime Database"
  8. Click "Create Database", choose any location, select "Start in test mode", click Enable
  9. Paste the config below and click Connect!
