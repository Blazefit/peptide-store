# HUMAN+ — Design Brief & Production Kit
### "The Periodic Table of Enhancement" t-shirt line

A streetwear/athleisure brand that treats peptides and hormones like elements on a
periodic table. Each compound gets an element-style tile: a symbol, a number, the
name, a formula/spec line, and a tagline. Positioning: **clinical precision meets
"factory default is not final."** Audience: gym / biohacker / longevity / TRT culture
who wear their optimization as identity.

> **Wordmark:** `HUMAN` in a heavy grotesque, `+` in the accent color.
> **Line:** MODIFIED · ENHANCED · OPTIMIZED

---

## The two-family numbering system (this is the important design rule)

Peptides have **amino acids**; steroids do **not** (they're not made of amino acids).
So the table uses two families, color-coded — which makes it look intentional and
scientific instead of inconsistent:

| Family | What it is | The "atomic number" = | Accent color |
|---|---|---|---|
| **PEPTIDE** | chains of amino acids | **amino-acid count** (HGH = 191) | mint/electric green `#2BE8B0` |
| **HORMONE** | steroids & small-molecule hormones | **molecular weight, g/mol** (Test = 288) | amber/gold `#FFB020` |

Base art is **white + one family accent on a dark garment**.

## The 5 starter collections

1. **Element of the Enhanced** (flagship) — one oversized tile, museum-clean. Start with **Te, Gh, Bp**.
2. **The Stack** — 3-6 tiles in a row = a real protocol stack (e.g. recovery: Bp · Tb · Gh).
3. **Half-Life** — a tile dissolving into a peptide-chain / decay-curve. Minimal, 2-color.
4. **Factory Default → Human+** — the `Hs → Hs+` two-tile concept. Most on-brand.
5. **Molecular Anatomy** — the 2D structural diagram as poster art, tile as a corner stamp.

## Master prompt (for vector-capable AI tools)

Paste into **Recraft V3 / Illustrator Text-to-Vector / Ideogram / Kittl**, swap brackets:

> Design a **vector, print-ready t-shirt graphic** for streetwear brand **"HUMAN+"**,
> themed as a *Periodic Table of Human Enhancement*. Centerpiece: a single
> **periodic-table element tile** for **[COMPOUND]** — large symbol **"[SYM]"** centered,
> a number **[NUMBER] [aa | g/mol]** top-left, full name **"[NAME]"** below the symbol,
> a one-line tagline **"[TAGLINE]"** at the bottom of the tile.
> Style: **clean clinical lab aesthetic meets bold athletic streetwear**, strong geometry,
> confident negative space, **flat spot-color shapes, no gradients, no photo detail.**
> Color: white + **[ACCENT]** on a dark background. Composition centered, fits a 12x14in
> print area. Output: crisp clean line art, solid fills, isolated on transparent background,
> **no gibberish text, no extra small text**, no mockup/garment — artwork only, flat front view.

**Append to every prompt:**
```
PRINT SPECS: vector line art, flat solid spot colors only (no gradients/halftones),
max 3 colors, high contrast, transparent background, centered within 12in x 14in
live area, min line weight 1.5pt, no thin isolated text, no mockup. Front flat view only.
```

## Step-by-step: from zero to printer

1. **Lock the brand kit.** Pick final accent greens/golds, the heavy grotesque for the
   wordmark/symbol (Neue Haas Grotesk / Helvetica Now / Space Grotesk) and a mono for
   the numbers/specs (JetBrains Mono). Buy the licenses.
2. **Pick your first drop** — 3 to 5 tiles. Suggested: **Te, Gh, Bp** + the **Hs→Hs+** concept.
3. **Generate or build the art.** Two paths:
   - **Path A (recommended, vector-native):** Recraft V3 / Illustrator Generative / Ideogram → export SVG/PDF.
   - **Path B (raster→vector):** Midjourney/DALL·E PNG → vectorize (Illustrator Image Trace / Vectorizer.ai) → clean up.
   - **Path C (already done for you):** edit `generate_tiles.py` in this folder and re-run — it outputs real, layered SVGs.
4. **Re-set all text in real fonts.** Never trust AI typography. Type the symbol, name,
   number, and tagline yourself in Illustrator/Affinity, then **outline the fonts**.
5. **Reduce to spot colors** so screen-print stays cheap (2-3 screens max). For DTG, full
   color is fine but flat art still prints crispest.
6. **Build the print file:** vector `.AI` or `.PDF`, fonts outlined, art sized to ~12x14in,
   plus a 300 DPI transparent PNG backup. Confirm the printer's template + Pantone/CMYK spec.
7. **Mock on garments** (Printful/Printify or the printer's templates) for the storefront.
8. **Sample, revise, run.** Order one blank-print sample per design before a bulk run.

## What's already in this folder

- `generate_tiles.py` — the reusable generator. Edit the `ELEMENTS` table or `PALETTE`,
  run `python3 generate_tiles.py`, and it rebuilds every SVG + PNG preview.
- `svg/` — editable, print-ready vector files (open in Illustrator/Affinity/Inkscape).
- `preview/` — PNG previews rendered on a black "garment" so you can eyeball them fast.

To regenerate after edits:
```bash
cd designs && python3 generate_tiles.py
```

## Compliance note (keep it lifestyle, not medical)

Selling apparel that references these compounds is fine. Keep all shirt copy in
**identity/lifestyle** language ("modified," "enhanced," "the original upgrade") and
**avoid medical claims or dosing instructions** on the products and marketing, so you
stay clear of FDA/advertising issues. The taglines above are intentionally attitude,
not advice.
