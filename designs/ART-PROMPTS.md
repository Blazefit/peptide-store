# HUMAN+ MYTHOS — DALL·E / ChatGPT Art Prompt Pack

The MYTHOS page slider has **two forms per character: MYTHIC and ANIME FORM**. So each character below has **two prompts** — generate both. Within each form, the first paragraph (HOUSE STYLE) is identical on purpose: that's what keeps the set cohesive.

**Workflow**
- Do all MYTHIC prompts in one ChatGPT chat, all ANIME prompts in another — consistency improves when the chat remembers the house style.
- Too colorful/cartoonish in MYTHIC? reply *“darker, more desaturated, more painterly, more serious.”* Too dull in ANIME? reply *“brighter, bolder line art, more vibrant, more dynamic.”*
- DALL·E can't do transparent backgrounds — that's fine, I drop each image into the card frame.
- **Save each image with the exact filename shown** into `designs/mythic_art/`, then tell me and I'll auto-wire them into the cards.
- Use the largest portrait size offered (1024×1792 ≈ the 6:7 card).
